# 🐍 AntiFraud Backend Service

Бэкенд-микросервис системы AntiFraud Monitoring на базе **Python FastAPI**. Отвечает за прием медицинских транзакций, исполнение правил автоматической фильтрации (Hard Block, Velocity Rules, Cost Outliers), хранение данных в потокобезопасной базе в памяти и симуляцию потоков данных.

---

## 📁 Структура папки бэкенда

```
backend/
├── app/
│   ├── database/
│   │   ├── __init__.py
│   │   └── db.py            # Потокобезопасная БД в памяти (InMemoryDatabase) с симуляционными данными
│   ├── models/
│   │   ├── __init__.py
│   │   └── schemas.py       # Pydantic-модели и энумы (Patient, Doctor, Clinic, Service, Transaction)
│   ├── routers/
│   │   ├── __init__.py
│   │   ├── dashboard.py     # Эндпоинты агрегированной статистики и реестра кейсов
│   │   ├── simulation.py    # Эндпоинты генерации и сброса симуляционных транзакций
│   │   └── transactions.py  # Эндпоинты проверки и получения списка транзакций
│   ├── services/
│   │   ├── __init__.py
│   │   ├── fraud_detector.py # Основной движок валидации и проверки правил фрода
│   │   └── generator.py      # Генератор случайных реалистичных логов и аномалий
│   ├── __init__.py
│   └── main.py              # Точка входа приложения FastAPI и регистрация CORS/роутов

```

---

## 🛠️ Технологический стек

* **Язык программирования:** Python 3.10+
* **Фреймворк:** FastAPI
* **Валидация и схемы:** Pydantic v2
* **Сервер:** Uvicorn
* **База данных:** In-memory Database с `threading.Lock()` для обеспечения потокобезопасности при параллельных запросах
* **Контейнеризация:** Docker (`python:3.10-slim`)

## 🚀 Эндпоинты API

При запущенном бэкенде интерактивная документация Swagger UI доступна по адресу:  
👉 **`http://localhost:8000/docs`**

### 1. Транзакции (`/api/transactions`)
* `GET /api/transactions` — Получение списка проверенных транзакций с поддержкой пагинации (`page`, `page_size`), фильтрацией по статусу (`status`) и поиском (`search`).
* `POST /api/transactions/check` — Проверка одной произвольной транзакции через антифрод-движок в режиме реального времени.

### 2. Аналитика и Дашборд (`/api/dashboard`)
* `GET /api/dashboard/stats` — Получение показателей KPI (сумма спасенных средств, заблокировано, в красной зоне) и данных для графиков (тренды, регионы, топ услуг).
* `GET /api/dashboard/cases` — Реестр выявленных кейсов фрода с привязкой к клиникам и правилам.

### 3. Симуляция данных (`/api/simulation`)
* `POST /api/simulation/generate?count=100` — Генерация заданной порции транзакций с искусственными аномалиями.
* `POST /api/simulation/reset` — Сброс базы данных к исходному состоянию.
