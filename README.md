# AntiFraud Monitoring System (ИИС Департамента экономических расследований МФ РК / ФСМС)

Автоматизированная система мониторинга, выявления и пресечения мошеннических схем, приписок медицинских услуг и аномалий при расходовании средств Фонда социального медицинского страхования (ФСМС) Республики Казахстан.

---

## Назначение и задачи системы

Система разработана для аналитиков и оперативных сотрудников Департамента экономических расследований (ДЭР МФ РК) и предназначена для:
1. **Пресечения приписок и фрода** при оказании медицинских услуг в клиниках и больницах.
2. **Предотвращения нецелевого расходования средств** бюджета ФСМС.
3. **Автоматического анализа транзакций** в режиме реального времени с применением правил Hard Block, Velocity Rules и выявления финансовых аномалий.
4. **Визуализации географии инцидентов** на карте регионов Казахстана (ADM1) с привязкой к конкретным филиалам и медицинским организациям.
5. **Формирования протоколов нарушений** для проведения проверок и изъятия материалов.

> **Примечание:** В демонстрационном режиме система использует виртуальный движок эмуляции транзакций (`LogGenerator`), который генерирует реалистичный поток медицинских услуг и аномалий без использования конфиденциальной врачебной тайны.

## Быстрый запуск

### Вариант 1: Запуск через Docker (Рекомендуемый)

Требуется установленный **Docker Desktop**.

**Через консоль:**
```bash
docker compose up --build -d
```

* **Интерфейс системы (Frontend):** [http://localhost:5173](http://localhost:5173)
* **Документация бэкенда (Swagger API):** [http://localhost:8000/docs](http://localhost:8000/docs)

Остановка контейнеров:
```bash
docker compose down
```

---

### Вариант 2: Локальный запуск без Docker

#### 1. Запуск Бэкенда (Python FastAPI):
```bash
cd backend
python -m venv venv

# Включение виртуального окружения (Windows PowerShell):
.\venv\Scripts\Activate.ps1
# (Linux / macOS): source venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

#### 2. Запуск Фронтенда (React + Vite):
```bash
cd frontend
npm install --legacy-peer-deps
npm run dev
```

## Реализованные алгоритмы выявления фрода

1. **Грубые логические ошибки (Hard Block):**
   * **Gender Conflict:** Несоответствие пола пациента оказываемой процедуре (например, услуга гинеколога для пациента мужского пола).
   * **Deceased Patient ("Мертвые души"):** Попытка проведения транзакции на гражданина со статусом `DECEASED` в базе ЗАГС.
   * **Doctor on Leave ("Врач-призрак"):** Регистрация приема у врача, находящегося в отпуске или на больничном (`is_on_leave == True`).

2. **Временные аномалии (Velocity Rules):**
   * **Rubber Day ("Резиновый день"):** Превышение предельной нормы суммарной длительности оказания услуг доктором за одни сутки (более 12 часов).
   * **Overlapping Bookings:** Физически невозможная запись одного пациента или врача на несколько процедур одновременно.

3. **Финансовые и статистические отклонения:**
   * **Cost Outliers:** Выявление услуг с аномальным завышением цены за пределы статистической нормы ($\mu \pm 2\sigma$).
   * **High Clinic Violation Ratio:** Выделение медицинских организаций в «Красную зону» при высоком проценте отклонений.
